## Preview
Open `index.html` in a browser. Use the "View my productivity" link to open the tracker.

## Important limitation
The tracker currently uses browser localStorage. That means sessions are stored only in the browser that recorded them; this is not yet a genuinely shared public dashboard. For real public access across devices, the next step is to add authentication/admin controls and a hosted database/API, then deploy both sites.

## Before publishing
1. Replace `AK` with your preferred public initials/brand.
2. Replace `hello@example.com` with your professional email.
3. Add verified project details, screenshots, GitHub links, and certificates.
4. Decide which productivity data should be public. Avoid exposing private notes or sensitive schedules.
5. Connect the productivity app to a shared backend before describing its data as live public data.
